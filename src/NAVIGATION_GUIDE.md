## 🗺️ Main Navigation Flow

### 1. **Start Page** (`startPage`)
**Description:** Game introduction and entry point
- → **Main Menu** - Click "Enter AgriVerse"

### 2. **Main Menu** (`mainMenu`)
**Description:** Central hub for all game modes
- → **Player Hub** - Main game dashboard
- → **Features Overview** - View all available features
- → **Start Playing** - Jump into gameplay

### 3. **Player Hub** (`playerHub`)
**Description:** Your personal farming command center
**Key Features:**
- Quick access to all major game systems
- Real-time stats and progress tracking
- Navigation to all specialized features

**Available Navigation:**
- → **Farm Dashboard** - View and manage your farm
- → **Character Customization** - Design your character
- → **Pet Customization** - Create your anime pet companion
- → **TerraAI** - AI farming assistant
- → **Learning Hub** - Educational content with XP system
- → **Farm Shop** - Buy tools and seeds with XP
- → **Guided Farming Practice** - Learn farming with companion
- → **World Map** - Explore climate shards
- → **Global Marketplace** - Trade resources
- → **Character Chat** - AI conversations
- → **Shard Explorer** - Discover new regions
