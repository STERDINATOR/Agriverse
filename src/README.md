## 🎮 Quick Start

### For Users (Live Demo)

1. **Launch the application**
2. **Clear browser cache** (Ctrl+Shift+R or Cmd+Shift+R) on first run
3. **Start playing** - all features work immediately!

**Note:** Application currently runs in Demo Mode with intelligent simulated AI responses. All features are fully functional.

### For Developers (Local Setup)

```bash
# Clone the repository
git clone https://github.com/yourusername/agriverse.git
cd agriverse

# Install dependencies
npm install

# Start development server
npm run dev

# Open browser to localhost:5173
```

See [CONTRIBUTING.md](./CONTRIBUTING.md) for detailed setup instructions.

## 🔧 API Configuration (Optional)

Want to use real generative AI instead of demo mode?

### Get Your Own Gemini API Key:

1. Visit [Google AI Studio](https://makersuite.google.com/app/apikey)
2. Create a new API key
3. Enable Gemini API for your project
4. Click "API Diagnostics" button (bottom-right in app)
5. Enter your API key and test

### Troubleshooting:

- **404 Errors**: API key lacks model access
- **403 Errors**: Enable Gemini API in Google Cloud
- **429 Errors**: Rate limit exceeded, wait or upgrade
- **Check Diagnostics**: Use "Test All Models" feature

**Note:** Demo Mode works great - real AI is optional!
