## 🚨 Common Issues (Quick Fixes)

### "API Key not valid"
```
Fix: Go to https://makersuite.google.com/app/apikey
     → Verify key is correct
     → Regenerate if needed
```

### Characters always the same
```
Diagnosis: Demo mode still active
Fix: Test connection in API Settings
     → Check browser console for errors
```

### "Rate limit exceeded"
```
Fix: Wait 60 seconds
     → Normal use won't hit this
```

### Network errors
```
Fix: Check internet connection
     → Try different network
     → Disable VPN if using
```
