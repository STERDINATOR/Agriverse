## 🚀 How to Use Demo Mode

### Generate Characters
1. Main Menu → "AI Character Creator"
2. Select:
   - **Art Style**: Anime, Manga, Shounen, Shoujo, etc.
   - **Role**: Farmer, Warrior, Mage, Guardian, Explorer
3. Click "Generate Character"
4. Get one of the 3 excellent pre-made characters
5. Customize with preset outfits and accessories

### Chat with Characters
1. PlayerHub → Character Chat
2. Choose your **personality type**
3. Start chatting!
4. Each personality responds differently:
   - Tsundere: "Hmph! It's not like I care... but I'll help!"
   - Genki: "Wow! That's amazing! Let's do our best! ⚡"
   - Kuudere: "...Fine. I suppose I'll answer."

### Get Farming Advice
1. Main Menu → TERRA-AI Assistant
2. Ask about:
   - Crop recommendations
   - Climate adaptation
   - Resource optimization
   - Strategic planning
3. Get intelligent, context-aware responses
