# Quick Start: AI Character Creator

## 🚀 Get Started in 3 Minutes

### Without API Key (Demo Mode)
1. Click **"AI Character Creator"** from Main Menu or Player Hub
2. Select art style (try "Anime" or "Shoujo")
3. Choose role (try "Farmer")
4. Click **"Generate Character"**
5. Get a unique character with backstory!

**No setup needed!** Demo mode works immediately with high-quality mock characters.

---

### With Gemini AI (Full Features)

#### 1. Get Free API Key (2 minutes)
```
→ Visit: https://makersuite.google.com/app/apikey
→ Sign in with Google
→ Click "Get API Key"
→ Copy your key (starts with "AIzaSy...")
```

#### 2. Add to Code (30 seconds)
```
→ Open: /services/AICharacterGenerator.ts
→ Line 32: Replace 'YOUR_GEMINI_API_KEY_HERE' 
→ Paste: Your actual API key
```

#### 3. Generate! (30 seconds)
```
→ Open AI Character Creator
→ Pick style + role
→ Click "Generate Character"
→ Get unique AI-generated character!
```

## 🎨 Character Creation Workflow

```
1. Choose Art Style
   ├─ Anime (classic)
   ├─ Manga (black & white)
   ├─ Chibi (cute)
   ├─ Shounen (action)
   └─ Shoujo (elegant)

2. Select Role
   ├─ Farmer (nature-focused)
   ├─ Warrior (combat-ready)
   ├─ Mage (mystical)
   ├─ Guardian (protective)
   └─ Explorer (adventurous)

3. Add Custom Details (optional)
   Example: "blue hair, cheerful, loves plants"

4. Generate!
   → Get complete character with:
      • Name & backstory
      • Detailed appearance
      • Stats (strength, intelligence, charisma)
      • AI-optimized image prompt

5. Customize (optional)
   ├─ Apply preset outfits (6 options)
   ├─ Change accessories (6 sets)
   └─ Regenerate image

6. Save & Use
   → Character saved to your profile
   → Use in chat, gameplay, etc.
```
